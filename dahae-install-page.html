다해 서버 설치 파일 만들기

서버를 빌린 뒤, 이 페이지에서 만든 내용을 서버 만들기 화면에 붙여넣으면 설치가 자동으로 시작돼요.

Make the setup text here, paste it into the server creation screen, and the install starts by itself.

1. 준비할 것

What you need

  1. 서버 호스팅 업체에서 Ubuntu 24.04 서버를 하나 준비하세요. (Ubuntu 24.04, or Debian 12)
  2. 쓰실 도메인(예: myshop.co.kr)을 준비하세요. 도메인 연결은 서버를 만든 뒤에 해도 돼요.
  3. 알림을 받을 이메일 주소를 준비하세요.

2. 정보 입력

Enter your details

healthchecks.io 같은 서비스의 핑 주소를 넣으면 설치 성공·실패를 알려 줘요. 없으면 비워 두세요.
이 내용에는 설치 인증 코드가 들어 있어요. 코드는 7일 안에 사장님 계정을 만들 때 써요. 다 쓰고 나면 이 화면과 복사한 내용을 지워 주세요.

3. 설치 인증 코드

Setup code: type it when you create the owner account

------

이 코드는 지금 이 화면에서만 확인할 수 있어요. 메모해 두세요.

4. 서버 만들기 화면에 붙여넣기

Paste into the server creation screen

고르기 어려우면 가이드 guide/09-클라우드별-설치.md 의 업체 목록을 보세요.

5. 서버가 켜진 뒤

After the server starts

  1. 업체 화면에서 서버의 공인 IP(고정 IP)를 복사하세요.
  2. 도메인 관리 화면에서 A 레코드 @ 와 www 를 그 IP 로 설정하세요. 설정 뒤 몇 분에서 한 시간 걸릴 수 있어요.
  3. 10~30분 기다린 뒤 브라우저에서 https://(도메인)/health 를 여세요. {"ok":true} 가 보이면 설치가 끝난 거예요.
  4. 그 다음 https://(도메인)/admin/ 을 열고 위의 설치 인증 코드로 사장님 계정을 만드세요.
도메인을 맞추기 전에 여러 번 주소를 열어도 괜찮아요. 다만 인증서 발급은 실패가 반복되면 잠시 쉬어야 해서 늦어질 수 있어요.

설치가 안 끝난 것 같으면 업체 화면에서 서버 콘솔(브라우저 SSH)을 열고 가이드 09 의 “문제가 생기면” 항목을 따라 주세요.
