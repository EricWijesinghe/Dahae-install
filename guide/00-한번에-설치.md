# 0. 한 번에 설치하기 (약 30분)

코드를 고칠 일도, 파일을 열어 고칠 일도 없어요. 서버를 하나 빌리고, 주소를 연결하고, 명령 한 줄을 붙여넣으면 끝나요.

**순서:** ① 서버 빌리기 → ② 도메인 연결 → ③ 명령 한 줄 → ④ 사장님 계정 만들기 → ⑤ 설정 마법사

## 준비물
| 준비물 | 어디서 | 비용 |
|---|---|---|
| 서버 1대 | 가비아, 카페24, NHN 클라우드, AWS Lightsail 같은 서버 임대 회사 | 업체 요금표 |
| 도메인 (예: `myshop.co.kr`) | 가비아, 카페24 같은 도메인 회사 | 업체 요금표 |
| 휴대폰 인증 앱 (Google Authenticator 등) | 앱 스토어 | 무료 |
| 사업자등록증, 통신판매업 신고증 | 이미 가지고 계신 서류 (설정 마법사의 사업장 정보에 입력해요) | - |
| PortOne 가입 (결제), Solapi 가입 (문자) | 각 회사 사이트. 결제 심사와 발신번호 등록에 시간이 걸려요 (기간은 회사 기준) | 회사별 요금 |

> 결제와 문자 가입은 설치 **전에** 시작하세요. 심사를 기다리는 동안 설치와 다른 설정을 먼저 할 수 있어요. 자세한 순서는 [2. 설정 마법사](02-설정-마법사.md)에 있어요.

## ① 서버 하나 빌리기
1. 서버 임대 회사에 가입하고 **서버(인스턴스) 만들기**를 눌러요.
2. 아래처럼 골라요.

   | 항목 | 고를 것 |
   |---|---|
   | 운영체제 | **Ubuntu 24.04 LTS** |
   | 사양 (권장) | **CPU 2개(2 vCPU), 메모리 4 GB** |
   | 사양 (최소) | 메모리 1 GB (1 GB 미만이면 설치가 멈춰요) |
   | 디스크 | 50 GB 면 충분해요 |
   | 지역 | 서울(한국) |

3. 서버가 만들어지면 화면에 나오는 **공인 IP 주소**(예: `3.38.12.34`)를 메모해요.
4. 방화벽(보안 그룹) 설정에서 **22, 80, 443** 포트를 열어요.

> 업체마다 화면 이름과 위치가 달라요. 업체별 순서는 [9. 클라우드별 설치](09-클라우드별-설치.md)를 보세요. (Each provider's screens differ; see guide 09.)

> 메모리가 2 GB 보다 작은 서버(1 GB)도 설치는 돼요. 설치 프로그램이 부족한 메모리를 디스크로 보충(스왑 2 GB)해 주지만 느릴 수 있어요. 손님을 받는 서버는 권장 사양으로 고르세요.

## ② 도메인 연결하기 (A 레코드)
1. 도메인을 산 회사 사이트에서 **DNS 관리**(또는 "DNS 설정") 화면을 열어요.
2. **A 레코드**를 하나 추가해요.
   - 호스트(이름): `@` (또는 비워 두기)
   - 값(IP 주소): ①에서 메모한 공인 IP
3. `www` 주소로 들어와도 열리게 하려면, 호스트를 `www` 로 해서 같은 IP 로 A 레코드를 하나 더 만들어요. (`www` 로 들어오면 자동으로 기본 주소로 옮겨져요.)
4. 저장해요. 반영까지 몇 분에서 1시간쯤 걸릴 수 있어요.

## ③ 명령 한 줄 붙여넣기
> **개발자·설치 담당용이에요.** 사장님은 아래 **가장 쉬운 방법**(검은 화면을 열지 않아요)으로 설치하세요.

1. 서버 회사 화면에서 **"브라우저에서 SSH 연결"**(또는 "콘솔 접속") 버튼을 눌러 검은 화면을 열어요.
2. 아래 한 줄을 그대로 복사해서 붙여넣고 Enter 를 눌러요.
   ```
   curl -fsSL https://raw.githubusercontent.com/EricWijesinghe/Dahae-install/v1.6.0/install.sh | sudo bash
   ```
3. 질문 두 개에 답해요.
   - **서비스 주소(도메인)** → `myshop.co.kr` 처럼 ②에서 연결한 도메인
   - **이메일** → 보안 인증서 안내를 받을 이메일 (없으면 그냥 Enter)
4. 기다려요. 새 서버는 처음에 10분쯤 걸릴 수 있어요.
5. "도메인이 아직 이 서버를 가리키지 않아요" 라고 나오면 당황하지 마세요.
   - 화면에 `A 레코드   myshop.co.kr   →   3.38.12.34` 처럼 **넣어야 할 값**이 나와요.
   - ②의 DNS 화면에서 그대로 고치고, 몇 분 뒤 검은 화면에서 **Enter** 를 누르면 다시 확인해요.
   - 나중에 하려면 `s` 를 입력해요. 설치는 계속되고, 도메인이 연결되면 보안 인증서(HTTPS)가 자동으로 발급돼요.
6. 끝나면 이런 화면이 나와요.
   ```
   ✔ 설치가 끝났어요!   (채널: stable)

   1) 브라우저에서 이 주소를 여세요:   https://myshop.co.kr/admin/
   2) 설치 코드를 입력하고 사장님 계정을 만드세요:

          설치 코드:  ABCD-2345-EFGH

   3) [설정] 메뉴에서 결제·문자·로그인 연동을 차례로 연결하세요.
   ```
7. **설치 코드(12자리)를 메모**해요. 다음 단계에서 한 번 써요.

> "앱은 정상이에요. HTTPS 인증서는 아직이에요." 라고 나왔다면 도메인 연결이 아직 반영되지 않은 거예요. ②를 다시 확인하고, 몇 분 뒤 `sudo dahae status` 를 입력해 "HTTPS 정상" 이 나오는지 보세요.

### 가장 쉬운 방법: 설치 페이지로 서버를 만들면서 설치하기 (검은 화면 없이)
서버를 만들 때 설치 내용을 붙여넣으면, 서버가 켜지자마자 설치가 시작돼요. 검은 화면에서 명령을 입력할 필요가 없어요.
1. 개발자에게 받은 **설치 파일 만들기 페이지**(`dahae-install-page.html`)를 내려받아 컴퓨터 브라우저로 열어요.
2. **도메인**(예: `myshop.co.kr`)과 **알림 이메일**을 입력해요. 완료 알림 주소는 없어도 돼요.
3. 체크 두 개를 눌러요: Ubuntu 24.04 를 골랐다, 방화벽에서 22·80·443 을 열어 둘 거다.
4. **[설치 파일 만들기]** → 화면에 나온 **설치 인증 코드**(12자리)를 메모해요. 그다음 **[복사하기]** 를 눌러요.
5. 호스팅 업체의 서버 만들기 화면에서 **"사용자 데이터(User data)"**, **"cloud-init"**, **"시작 스크립트"** 중 있는 칸에 그대로 붙여넣어요. 칸 이름과 위치는 [9. 클라우드별 설치](09-클라우드별-설치.md)에 있어요.
6. 서버를 만들고 **10~30분** 기다려요. 설치는 서버 안에서 혼자 진행돼요.
7. 업체 화면에서 서버의 **공인 IP** 를 복사하고, ②의 DNS 화면에서 A 레코드 `@` 와 `www` 를 그 IP 로 설정해요.
8. 10~30분 뒤 브라우저에서 `https://myshop.co.kr/health` 를 열어요. **`{"ok":true}`** 가 보이면 설치가 끝난 거예요. ④로 가세요.

> 설치 인증 코드는 **7일 안에** 쓰면 돼요. 그 사이 DNS 와 결제 가입을 천천히 해도 괜찮아요.
> 설치가 실패했는지 알고 싶다면 2번에서 **설치 완료 알림 주소**(healthchecks.io 같은 서비스의 핑 주소)를 넣으세요. 성공과 실패가 알림으로 와요.
> `/health` 가 안 열리면 업체 화면의 **브라우저 SSH 연결**에 들어가 `sudo dahae status` 를 입력하고, 그 화면을 개발자에게 보내세요.
> 설치 페이지와 복사한 내용에는 설치 인증 코드가 들어 있어요. 설치가 끝나면 이 페이지와 복사한 내용을 지워 주세요.

### 꼭 하세요: 보안 키 파일 보관 (지금은 개발자 도움이 필요해요)
서버의 `/opt/malkkeum/.env` 파일에 보안 키가 모두 들어 있어요. **이 파일이 없으면 백업을 되살릴 수 없어요.**
아직 콘솔에서 바로 받을 수 없어서, 개발자에게 **"보안 키 사본을 만들어 주세요"** 라고 부탁하세요. 개발자가 서버에서 `sudo dahae keys-backup` 으로 암호화한 파일을 만들어 전해 줘요.
사본은 **서버 밖(USB, 비밀번호 관리 앱)** 에 보관하고, 카카오톡이나 이메일 본문에 붙여넣지 마세요.

## ④ 사장님 계정 만들기 (설치 코드)
1. 브라우저에서 `https://도메인/admin/` 을 열어요.
2. "환영합니다! 사장님 계정을 만들어 주세요" 화면에 **설치 코드, 이름, 이메일, 비밀번호(12자 이상)** 를 입력해요.
3. 만든 이메일과 비밀번호로 로그인해요.
4. 처음 로그인하면 **2단계 인증 설정** 화면이 나와요. 휴대폰 인증 앱에 화면의 키를 추가하고, 앱에 보이는 6자리 숫자를 입력해요.


> 설치 코드를 잃어버렸거나 7일이 지났다면 설치를 도와준 개발자나 설치 담당에게 알려 주세요. 새 코드를 만들어 줄 거예요. 계정을 만든 뒤에는 코드가 더 이상 쓰이지 않아요.

## ⑤ 설정 마법사
1. 콘솔 왼쪽 메뉴에서 **[설정]** 을 눌러요.
2. 카드를 위에서부터 하나씩 채워요: 사업장 정보 → 결제 → 문자·알림톡 → 앱 푸시 → 로그인.
3. 카드마다 설명과 **[사이트 열기]** 버튼이 있어요. 값을 붙여넣고 저장한 뒤 **[연결 확인]** 을 눌러 확인해요 (PortOne 카드는 **[API 키 확인]**).
4. 자세한 순서는 [2. 설정 마법사](02-설정-마법사.md)를 보세요.

## 문제가 생기면
| 화면에 나온 말 | 해결 |
|---|---|
| "관리자 권한이 필요해요" | 명령 맨 끝이 `sudo bash` 인지 확인하고 다시 붙여넣기 |
| "80/443 포트를 다른 프로그램이 쓰고 있어요" | 서버에 다른 웹 서버가 깔려 있어요. `sudo systemctl disable --now nginx apache2` 를 입력한 뒤 설치 명령을 다시 실행 |
| "남은 디스크가 … 최소 5 GB 가 필요해요" | 디스크가 더 큰 서버를 고르기 |
| "서비스가 시작되지 않았어요" | `sudo dahae logs` 화면을 캡처해서 개발자에게 전달. 설치 명령을 다시 실행해도 안전해요 |
| 주소를 열면 "안전하지 않음" | 도메인 연결이 반영되기 전이에요. 10~30분 뒤 다시 열기 |
