# 사장님 가이드 — 콘솔 하루 사용법

콘솔 주소: `https://도메인/admin/` — 따로 설치할 프로그램 없이 PC·휴대폰 모두 앱처럼 쓸 수 있어요.

## 앱처럼 설치하기 (한 번만)
| 기기 | 방법 |
|---|---|
| PC (Windows) | **Edge** 또는 **Chrome** 으로 콘솔 주소 열기 → 주소창 오른쪽 **앱 설치** 아이콘(⊕) → [설치]. 시작 메뉴·작업 표시줄에 "다해 관리자" 아이콘이 생겨요 |
| 안드로이드 폰 | **Chrome** 으로 콘솔 주소 열기 → 오른쪽 위 ⋮ → **앱 설치** (또는 홈 화면에 추가). 홈 화면 아이콘으로 바로 열려요 |
| 아이폰 | **Safari** 로 열기 → 공유 버튼 → **홈 화면에 추가** |

새 기능은 업데이트할 필요 없이 다음에 열 때 자동으로 반영돼요.
`Ctrl + K` 를 누르면 메뉴나 예약번호를 바로 찾을 수 있어요.

## 매일 아침 5분
1. **대시보드**: 오늘 작업, 견적 대기, 미배정, 안 읽은 상담 숫자 확인
2. **미배정**이 있으면 [예약]에서 열어 파트너에게 연락하거나 일정 조정
3. **안 읽은 상담**은 [상담함]에서 답장 (고객 앱에 바로 알림이 가요)

## 시스템 상태 (매주 한 번, 문제 있을 때)
[시스템 상태]에서 서버가 건강한지 한눈에 봐요. 항목마다 **초록(정상) · 노랑(확인 필요) · 빨강(조치 필요)** 으로 표시돼요.

- **서버 상태**: 맨 위 색이 가장 나쁜 항목을 따라가요.
- **데이터베이스**: 응답 속도와 용량. 빨강이면 서버 재시작이나 설치 담당자 확인.
- **서버 디스크**: 여유 공간이 10% 아래면 빨강. 오래된 백업을 정리하거나 디스크를 늘려 주세요.
- **자동 백업**: 마지막 백업이 36시간 넘게 없으면 빨강. 설치 담당자에게 `sudo dahae backup` 확인을 요청하세요.
- **서버 오류 (24시간)**: 500번대 오류 건수. 많으면 노랑·빨강. 설치 담당자가 `sudo dahae logs` 를 보고 개발사에 전달해요.
- **결제 확인 필요**: 결제는 됐지만 자동 처리가 실패한 건이 있다는 뜻이에요. PortOne 관리자 화면에서 해당 결제를 확인하고 필요하면 직접 환불하세요.
- **결제 알림 (웹훅)**: 결제사 알림의 서명 검사가 실패했다는 뜻이에요. 설정 > 결제의 웹훅 시크릿을 다시 확인하세요.
- **외부 서비스**: 결제·문자·푸시·소셜 로그인마다 마지막 성공과 실패 시각, 오류 코드를 보여요. 빨강 항목 아래의 안내대로 설정 카드에서 키를 다시 붙여넣고 [연결 확인] 를 누르세요.

**자동 알림**: 문제가 반복되면 상담함에 알림이 쌓이고, 사장님 휴대폰으로 문자가 가요. 같은 문제는 6시간에 한 번만 보내요. [시스템 상태] 맨 아래 **알림 설정**에서 어떤 알림을 받을지, 조용한 시간(기본 밤 10시 ~ 아침 7시), 문자 받을 번호를 정할 수 있어요. 조용한 시간에 생긴 문제는 시간이 끝난 뒤 한 번 알려 드려요.

**결제 내역 불일치** (알림 설정의 "PortOne 결제 내역 불일치", 기본 켜짐): 매일 새벽 3시 이후 PortOne의 전날 결제 내역과 앱의 결제 기록을 맞춰 봐요. 금액이 다르거나, 한쪽에만 있는 결제가 있으면 알려 드려요. 대조는 하루에 한 번만 해요.

## 견적 (이사·입주 청소)
1. [견적 데스크]에 새 요청이 쌓여요. 파트너들이 낸 견적이 함께 보여요.
2. 마음에 드는 파트너 견적을 고르고 최종 금액을 입력 → [견적 보내기]
3. 고객이 예약금(10%)을 결제하면 그 파트너에게 자동 배정돼요.

## 파트너 관리
- [파트너]: 새로 가입한 파트너를 확인하고 **[승인]**. 문제가 있으면 [정지].
- 승인 전에 **[검증 체크리스트]** 를 채워요: 신분증 확인, 세금 유형 확인, 경력 확인, 비상연락처 확인. 네 항목을 모두 체크해야 승인돼요. 중간 저장은 [체크리스트 저장]으로 할 수 있어요.
- [프로필]: 사진, 소개, 고용 형태(프리랜서·직원·위탁), 입사일을 적어 둘 수 있어요. 비상연락처는 암호화되어 저장되고, 볼 때마다 기록이 남아요.
- [프로필] 의 **주민등록번호(또는 사업자등록번호)**: 지급명세서에 필요해요. 파트너에게 사용 목적(지급명세서 작성)을 설명하고 동의를 받은 뒤에 입력하세요. 저장하면 뒤 4자리만 보여요. 칸을 비워 두고 저장하면 기존 번호는 그대로 남아요. 원본은 **[원본 보기]** 를 눌러야 보이며, 인증 앱 코드를 다시 물어봐요. 볼 때마다 기록이 남아요.
- [파트너] 화면 맨 위 목록(줄마다 **승인 대기** 표시): 파트너가 초대한 팀원은 사장님이 **[승인]** 해야 고객 주소를 보고 작업을 받을 수 있어요. 승인 전에는 팀원 앱에 작업이 보이지 않아요.
- [정산]: 지급 예정 목록. [지급 요청]을 누르면 지급 건이 만들어져요. 직접 이체 방식이면 [계좌 보기] 로 정보를 확인해 이체하고 [이체 완료로 표시]. 토스 지급대행이면 [토스로 지급 요청] → [상태 확인]. 실패한 건은 [다시 시도]. 분쟁이 있는 건은 [보류] (지급 요청된 건은 보류할 수 없어요).

## 세금계산서
- [재무] 화면의 세무 항목에서 [세금계산서 업로드 CSV]를 누르면 아직 내보내지 않은 요청만 받아요. 한 번 받은 요청은 다음 내보내기에 다시 나오지 않아요(같은 기간을 다시 받으면 비어 있어요).
- 파일을 잃어버리거나 손상됐을 때만 [다시 내보내기]를 누르세요. 이미 받은 요청을 같은 파일로 다시 받아요. 확인 창에서 [다시 내보내기]를 한 번 더 눌러야 실행돼요.
- 홈택스에서 발행한 뒤에는 승인번호를 기록하세요.
- 결제를 전액 환불하면 아직 내보내지 않은 세금계산서 요청은 자동으로 취소돼요. 이미 내보냈거나 홈택스에서 발행한 요청은 목록에 그대로 남아 있어요. 이 경우 홈택스에서 수정세금계산서로 직접 취소하세요. 부분 환불이면 요청은 그대로 남아요.

## 마케팅
- [쿠폰 · 콘텐츠]: 홈 배너, 공지, 자주 묻는 질문을 한국어·영어로 편집. 고객에게 쿠폰 발급.
- [카탈로그 · 가격]: 서비스 가격, 시간대별 예약 가능 수, 이사 견적 공식 수정. 저장하면 앱과 웹사이트 가격이 바로 바뀌어요.
  - 개수로 고르는 서비스(에어컨, 소파, 매트리스, 창문, 방역·소독)는 옵션 이름, 가격, 소요 시간, 옵션별 최대 개수와 다중 할인율(0~50%)을 여기서 고쳐요.
- [카탈로그 · 상품 묶음]: 앱 첫 화면의 큰 메뉴 4개(이사·입주 청소, 거주 청소, 가전·가구 청소, 방역·소독)의 제목, 순서, 그림, 들어가는 상품, 앱에 보일지를 고쳐요. 이사·입주 청소 묶음은 신축일 때와 구축일 때 상품, 집 크기 선택지도 여기서 정해요. 한 상품은 한 묶음에만 들어갈 수 있어요.
- [카탈로그 · 피크 요금]: 주말·공휴일·저녁 할증 비율과 상한. "정해진 가격·정기 청소에도 할증 적용"을 끄면 정해진 가격 예약과 정기 청소는 기본 가격으로 예약돼요(견적은 항상 할증을 보여줘요). 기본값은 꺼짐이라 켜기 전까지 예약 가격은 바뀌지 않아요. 켜서 저장하면 새 예약과 다음에 결제되는 정기 청소 회차부터 적용돼요. 할증분은 쿠폰·정기 할인 계산에도 포함되고, 파트너 정산액에도 반영돼요. 정기 청소 월 매출(MRR) 집계에는 포함되지 않아요.

## 운영 규칙 (사장님이 정하는 한도)
- 메뉴 **운영 규칙**에서 사업장 한도, 광고 발송 횟수, 포인트 한도, 파트너 품질 기간, 서버·알림 기준을 바꿀 수 있어요.
- 각 항목 아래에 **입력 가능 범위**와 **바로 적용** 또는 **서버를 다시 시작해야 적용**이 적혀 있어요. 값을 바꾼 뒤 [저장]을 누르세요.
- 광고 발송 횟수, 포인트 한도, 서버 알림 기준은 **기본값보다 낮게만** (또는 알림 기준은 **더 빨리 알리도록만**) 바꿀 수 있어요. 후기 신고 기준은 **기본값보다 높게만** 바꿀 수 있어요. 안전을 위한 제한이에요.
- **업무 알림**(기본으로 켜짐): 확정됐는데 24시간 넘게 기사님이 안 정해진 예약, 오늘 방문 예약의 당일 취소 비율이 30%를 넘을 때(예약 5건 이상일 때만), 부가가치세 신고 기한 7일 전(법인은 1·4·7·10월 25일, 개인 일반과세자는 보통 1·7월 25일이라 세무 담당자와 날짜를 꼭 확인하세요). 기준 숫자는 [운영 규칙] 안의 서버·알림 기준에서 바꿀 수 있어요. 예약 흐름 카드(대시보드·상태 페이지)에서 배정까지 걸린 시간, 미배정 예약, 당일 취소, 서비스별 미도착 비율을 볼 수 있어요.
- **기본값으로**를 누르면 설치 때의 값으로 돌아가요. 바꾼 내역은 서버 기록에 남아요.
- **파트너 교육 완료 전 일감 수락 막기**는 기본으로 꺼져 있어요. 켜면 필수 교육을 끝내지 않은 파트너는 일감을 수락할 수 없어요. 교육 화면이 준비된 뒤에 켜세요.
- "여기서는 바꿀 수 없어요"라고 표시된 항목(예: 결제 대사 주기)은 개발자에게 문의하세요.

## 직원
- [직원]에서 상담 직원 계정을 만들 수 있어요. **상담원** 권한은 예약·상담만, **관리자**는 모든 설정까지.

## 활동 기록 (사장님만)
[활동 기록]에서 누가 언제 무엇을 했는지 최신순으로 볼 수 있어요. 환불, 고객 연락처 조회, 직원 변경, 정산 보류 같은 일이 여기에 남아요.

1. **기간**: 오늘, 최근 7일, 최근 30일, 전체 기간 중에서 고르세요. 기본은 최근 7일이에요.
2. **누가**, **무엇을**: 드롭다운에서 고르면 그 사람이나 그 종류의 일만 보여요.
3. 줄을 누르면 상세 내용이 나와요. 기록은 지울 수 없어요. 이상한 일이 보이면 설치 담당자나 개발사에 알려 주세요.

## 탈퇴·개인정보 요청
- [탈퇴·개인정보 요청]에서 고객의 **전화번호**를 입력하고 [찾기].
- **[자료 사본 받기 (CSV)]**: 고객이 요청한 개인정보 사본을 엑셀 파일로 받아요. 받은 파일은 고객에게만 전달하세요.
- **[탈퇴 처리]** (관리자만): 고객 전화번호를 다시 입력해야 진행돼요. 이름·연락처 등은 지워지고 **되돌릴 수 없어요**. 예약·결제 기록은 법에 따라 남아요.
- 아래 **처리 기록**에 모든 요청이 완료·실패로 남아요.
## 내 계정 (소유자)
- 사장님 계정은 **소유자**예요. 소유자는 한 명만 있고, 계정 보안과 서버 설정을 바꿀 수 있어요.
- 처음 설정할 때 만든 관리자가 소유자예요. 소유자가 없으면 관리자가 [내 계정] → [내가 소유자 되기]로 지정할 수 있어요.
- 처음 로그인하면 인증 앱(OTP) 설정 후 **복구 코드 10개**가 나와요. 종이에 적어 안전한 곳에 보관한 다음 [적어 보관했어요]를 눌러야 소유자 기능이 열려요.
- 소유자 기능을 쓸 때마다 인증 앱의 6자리 번호를 물어봐요. 번호는 한 번만 쓸 수 있어요.
- [내 계정]에서 할 수 있는 일: 알림 받을 휴대폰 바꾸기(이전 번호로 안내 문자가 가요), 비밀번호 바꾸기(모든 기기에서 로그아웃돼요), 모든 기기에서 로그아웃, 복구 코드 다시 만들기(기존 코드는 못 쓰게 돼요), 소유자 넘기기(넘겨받을 관리자도 자기 인증 번호를 입력해야 해요).
- 인증 앱을 잃어버리면 소유자 기능을 쓸 수 없어요. 서버 담당자가 한 시간짜리 초기화 코드를 만들어 주면, 그 코드와 비밀번호로 2단계 인증을 다시 설정할 수 있어요. (초기화 코드 입력 화면은 아직 콘솔에 없고, 서버 담당자가 도와줘야 해요.)

## 도메인 바꾸기
[설정] → **도메인** 에서 지금 주소와, 아직 응답하는 예전 주소를 봐요.
0. 처음 한 번: [설정] → **서버 승인 코드** → **[등록하기]** 로 인증 앱에 추가해요. 이것 없이 바꾸면 인증 앱 번호를 쓴 뒤에 서버가 거절해요.
1. 새 도메인의 A 레코드를 이 서버 IP 로 넣어요. 예전 도메인의 레코드는 그대로 두세요.
2. 새 도메인을 입력하고 **[DNS 확인]**. "이 서버를 가리켜요" 가 나오면 다음으로 가요.
3. **[바꾸기]** → 인증 앱 번호 → 서버 승인 코드. 서버가 먼저 새 주소를 확인하고, 응답하지 않으면 아무것도 바꾸지 않고 이유를 보여 줘요. 응답하면 30초쯤 멈췄다가 새 주소로 돌아와요. 승인 창에는 서버가 직접 쓴 작업 내용이 보여요. 입력한 도메인과 다르면 승인하지 마세요.
4. 체크리스트의 값을 복사해 각 사이트(PortOne·토스 웹훅, PG 사이트 주소, 네이버 콜백 **추가**, 검색 등록, 스토어 주소)에 넣고 체크해요.
5. 설치된 앱은 예전 주소로 계속 작동해요. 새 스토어 빌드가 나오고 최소 앱 버전을 올린 뒤에만 예전 주소를 **은퇴**시키세요 (인증 앱 번호 필요).

## 이럴 땐 이렇게
| 상황 | 할 일 |
|---|---|
| 고객이 결제했는데 예약이 안 보인다고 함 | 1~2분 기다리면 자동 복구돼요 (결제사와 자동 대조). 그래도 없으면 [예약] 검색에 전화번호 입력 |
| 결제가 안 된다는 문의가 많음 | [설정] → 결제 카드의 [API 키 확인] |
| 인증 문자가 안 온다는 문의 | [설정] → 문자 카드의 [연결 확인], Solapi 잔액 확인 |
| 설정 카드가 빨간색 | 카드 안 안내대로 키를 다시 붙여넣고 저장 |
| 서버가 안 열림 | 설치 담당자에게 `sudo dahae status` 확인 요청 |
